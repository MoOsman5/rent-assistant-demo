# rent-assistant-demo

نسخة تجريبية من مساعد بحث لقضايا الإيجارات في مصر (الإخلاء لعدم سداد الأجرة).

- صفحة واحدة: `index.html`
- القاعدة: 15 حكم نقض بملخصات لم يراجعها محامٍ بعد
- الناتج مساعدة في البحث وليس رأيًا قانونيًا

لا يوجد أي مفتاح API في هذا المستودع. المفتاح يُمرَّر في الرابط ويُحفظ في متصفح المستخدم فقط.
